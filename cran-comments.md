# CRAN comments for semPlot 1.2.0

This is a version update of the existing CRAN package semPlot. The current
CRAN release is 1.1.8.

## Summary of the release

See NEWS for the full list of changes. Highlights:

* New model support: PLS-SEM (`seminr`, `cSEM`), `metaSEM` stage-2 models,
  `lavaan.mi` pooled multiple-imputation fits, `piecewiseSEM` `psem()`
  models, and `psych` `fa()`/`omega()` objects.
* `blavaan` objects are now imported natively via lavaan-method inheritance
  instead of overwriting their class.
* New importer-registration API and a `semPlotModel` validator.
* Several previously hard dependencies (`sem`, `XML`, `lisrelToR`,
  `rockchalk`, `OpenMx`) moved from Imports to Suggests, reducing the
  installation burden; they are loaded conditionally where needed.
* Added a regression test suite under `tests/`.
* Added Adela-Maria Isvoranu as a contributor.

### Note on DESCRIPTION

The source DESCRIPTION previously carried hand-maintained `Packaged:`,
`Author:`, `Repository:` and `Date/Publication:` fields left over from a CRAN
tarball. These are generated by `R CMD build` and by CRAN, and the stale
`Author:` field had drifted out of sync with `Authors@R`. They have been
removed so that `Author:` is generated from `Authors@R`.
